# Security

This repository is a sanitized portfolio build. Do not commit live credentials, API keys, access tokens, private webhook URLs, customer data, or private resource identifiers.

## Report a security issue

Do not put a secret or a private deployment detail in a public issue. Contact the repository owner through the public profile instead.

## Deployment rule

Use platform credential stores or environment variables for secrets. Rotate a secret immediately if it enters Git history or a public artifact.
